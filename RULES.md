# Правила проверки поставщиков (от Дмитрия)

1. Трейдеры НЕ отклоняются. Роль: manufacturer / trader / manufacturer_trader / unknown — отдельная категория.
2. Санкции, суды, уголовные дела владельцев НЕ являются основанием для отклонения. Формулировка нейтральная: «есть сложности» — и всё. Такие поставщики нужны: они решают вопросы.
3. Отклонять (rejected) можно только если: юрлица не существует, оно ликвидировано/банкрот. Несоответствие HS — НЕ основание для отклонения: компания сохраняется в базе, код исправляется на фактический, вердикт `accepted_hs_corrected` с оговоркой. Проверка 23.11.2026: Дмитрий снял HS-отклонения, все ранее отклонённые по HS восстановлены.
4. Выручка и объём экспорта — обязательные поля. Нет данных — null, не выдумывать.
5. **Проверять фактичность отгрузок, а не заявления (23.11.2026).** Для каждой компании отдельно фиксировать: (а) были ли реальные экспортные отгрузки — по таможенным/B-L записям с датой и направлением; (б) поставки внутри Индии — по GST-оборотам, контрактам, публичным закупкам; (в) чем подтверждено — ссылка на конкретную запись, а не «сайт заявляет». Слова сайта, каталога и IndiaMART фактом не считаются: статус `заявлено, не подтверждено`. Если отгрузок нет ни по экспорту, ни по внутреннему рынку — писать прямо «следов поставок не найдено», не смягчать формулировкой «условно принят».
